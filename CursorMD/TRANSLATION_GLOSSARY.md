# Translation Glossary

Use consistent terms across all languages. When adding or translating strings, prefer these terms.

| English | Use for | Notes |
|--------|---------|-------|
| **Patient** | Person receiving care | Not "client" in clinical context |
| **Appointment** | Scheduled visit | |
| **Prescription** | Doctor-ordered medication/treatment | |
| **Invoice** | Billing document | |
| **Queue** | Waiting list for consultations | |
| **Clinic** | Healthcare facility | |
| **Dashboard** | Main overview screen | |
| **HIPAA** | US health privacy regulation | Do not translate; keep "HIPAA" |
| **GDPR** | EU data regulation | Do not translate; keep "GDPR" |
| **PHI** | Protected Health Information | Do not translate; keep "PHI" |
| **Vital signs** | BP, pulse, temperature, etc. | |
| **Clinical note** | SOAP/visit documentation | |
| **Prescription validity** | Days until prescription expires | |
| **Low stock** | Inventory below threshold | |
| **Batch / Lot** | Inventory batch with expiry | |
| **Subscription** | Billing plan | |
| **Tenant** | Clinic/organization in multi-tenant system | Technical; use sparingly in UI |
