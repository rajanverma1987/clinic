## Implementation (Codebase – 100% follows this doc)

- **Plans:** `scripts/seed-database.js` – FREE $0, SOLO $29, CLINIC $49 (most popular), ENTERPRISE $199. Team limits: FREE 1, SOLO 3 (1 doctor + 2 staff), CLINIC 10 (5 doctors + 5 staff), ENTERPRISE unlimited. Re-run seed to update existing plans.
- **Included services:** `lib/constants/plan-features.js` – FREE/SOLO/CLINIC/ENTERPRISE feature lists match § Plan Structure Overview. `getFeaturesForTier(tier)` returns full list per plan.
- **Quick Feature Comparison:** `lib/constants/subscription-spec.js` – `COMPARISON_TABLE_ROWS` has exactly 14 rows in doc order (Doctor Accounts, Staff Accounts, Patient Records, Appointments/month, SOAP Notes, Prescriptions, SMS Reminders, Document Storage, Billing, Inventory, Reports, Locations, Backups, Support). FREE column uses ❌ where doc has ❌.
- **Add-Ons, Which Plan, Payment & Terms, Special Offers, Get Started, FAQ:** Same file + `lib/i18n/locales/en.json`, `es.json`, `fr.json`. Payment & Terms = 7 bullets (`paymentTerms1`–`paymentTerms7`). Section order on `/subscription`: Current Plan → Plan cards → Quick Feature Comparison → Add-Ons → Which Plan is Right for You? → Payment & Terms → Special Offers → Get Started → FAQ. All subscriptionSpec keys (including `bestForLabel`, `contactSupport`) are i18n for EN/ES/FR.
- **Subscription page:** `app/subscription/page.jsx` – Layout, PageHeader, Card blocks, design tokens. Plan cards use `SubscriptionCard` with features + maxUsers/maxPatients/maxStorageGB from API (seed sets correct limits).
- **Pricing page:** `app/pricing/page.jsx` – Same 4 plans; `YEARLY_SAVE`: SOLO 58, CLINIC 98, ENTERPRISE 398.
